Step-by-step guide

Find company and job files

Use the central Files page without confusing company documents with job records.

3 stepsAbout 1 min Updated October 11, 2026
Steps
1Choose the file collection2Prepare a company document3Find the record behind a job file
1
Choose the file collection
Company Files holds reusable company documents. Job Files collects files from jobs. Packets groups submission documents, and Shared shows outbound document sharing. Use the category chips to narrow the current collection.
2
Prepare a company document
From Company Files choose Upload File. Select the file, give it a clear name and choose the matching category. Review it before Upload.
3
Find the record behind a job file
On Job Files, filter by Plans, Site photos, Submittals, Quotes, Sent with quote requests or Bills. Records are grouped by job. A file title opens its linked file or section; the open icon takes you to the source section on that job.
That's it!You've completed all 3 steps.
