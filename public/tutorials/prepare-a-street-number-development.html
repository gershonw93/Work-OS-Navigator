Step-by-step guide

Prepare a street-number development

Set up a run of houses without entering each number separately.

2 stepsAbout 1 min Updated October 11, 2026
Steps
1Set the street and numbering pattern2Review the count and sample names
1
Set the street and numbering pattern
Projects > Bulk Add > Street numbers. Add a name prefix, client, street name and City, state & ZIP. First number starts the run; Increment controls the gap between numbers; How many is the total job count.
2
Review the count and sample names
Choose the project type and check the start date. Read the examples generated by your number pattern, then check Create projects shows the intended count. Verify the whole street and numbering pattern before creating the development.
That's it!You've completed all 2 steps.
