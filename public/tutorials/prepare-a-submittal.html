Prepare a submittal

Put product data and the details needed for review in one place.

2 stepsAbout 1 min Updated October 11, 2026
Steps
1Open Docs > Submittals2Prepare the document and review its details
1
Open Docs > Submittals
Use Add Submittal for tech sheets, shop drawings and product data. Confirm you are on the right project before uploading.
2
Prepare the document and review its details
Use Scan Submittal for auto-fill or enter a title, type, trade, manufacturer, model and spec section. Attach the actual tech sheet/drawing/product data in the required File field. Review extracted fields and add notes for the reviewer before Add Submittal.
That's it!You've completed all 2 steps.
