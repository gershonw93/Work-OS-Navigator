Step-by-step guide

Find projects with search and views

Get to the right job using filters, a list or the map.

3 stepsAbout 1 min Updated October 11, 2026
Steps
1Narrow the project list2Use the view that fits the question3Find jobs geographically
1
Narrow the project list
Open Projects. Search by name, address or client, then filter by type or status and choose a sort order. The status cards give a quick way to focus on active, planning, on-hold or completed jobs. A development card can hold multiple jobs.
2
Use the view that fits the question
Grid shows project cards. List puts jobs into rows for scanning the same details across jobs. Use Open or the project name to enter the correct job after checking its address and client.
3
Find jobs geographically
Map shows colored project pins beside a project list. Choose a job or pin, then its popup to open it. Use the map zoom buttons to separate nearby pins. Unit and floor jobs can share one building location.
That's it!You've completed all 3 steps.
