Step-by-step guide

Prepare bulk projects from a list

Bring in real addresses from a sheet, PDF, photo or pasted list.

2 stepsAbout 1 min Updated October 11, 2026
Steps
1Choose your list source2Fill missing locations, then read the list
1
Choose your list source
Projects > Bulk Add > From a list. Choose the project type that fits, add a client if needed and check the start date. A spreadsheet (.xlsx or .csv) is read by its column headings. A PDF or photo uses one AI scan.
2
Fill missing locations, then read the list
You can paste addresses instead of choosing a file. City and State are fallbacks for rows without a location. Lists under location headings can carry those headings onto their rows. Use Read the list to continue, then check parsed addresses before creating jobs.
i
Check the start date shown rather than assuming it is today where you are.
That's it!You've completed all 2 steps.
