Step-by-step guide

Set up client selections

Plan what the client must choose before lead times hold up the job.

3 stepsAbout 1 min Updated October 11, 2026
Steps
1Open Finance > Selections2Use the standard board without adding unwanted categories3Add a specific decision with its allowance and deadline
1
Open Finance > Selections
Use Start the standard board for a category-based setup or Add one selection for a specific choice. Copy client link is a sharing route; prepare the board before giving anyone access.
2
Use the standard board without adding unwanted categories
The app suggests categories for the project type and shows typical lead time and the work each category can block. Untick anything the job does not include. Check the item/category count before Add these.
3
Add a specific decision with its allowance and deadline
Choose category, describe the choice, and add its room/location and budget allowance. Set Decide by early enough for the actual supplier lead time. A typical lead time is a planning cue, not a supplier promise. Link a budget line when appropriate, then Add.
That's it!You've completed all 3 steps.
