Step-by-step guide

Add a Directory contact

Keep contractors, suppliers, inspectors, and workers in the right place.

3 stepsAbout 1 min Updated October 11, 2026
Steps
1Choose the contact type2Fill the contact details3Check before inviting
1
Choose the contact type
Open Directory > Add Contact. Choose GC, Subcontractor, Inspector, Supplier, Worker, or Other to match the person or company.
2
Fill the contact details
Enter the required name and email. Add the phone, address, trade, or license details that apply, then use the add button for that contact type.
3
Check before inviting
Adding a contact and inviting them are separate actions. Use Directory search or the type tabs to find them later. Only use the invitation action when you intend to send an invite.
That's it!You've completed all 3 steps.
