Choose project preferences

Set starting project choices without treating them as rules for every job.

2 stepsAbout 1 min Updated October 11, 2026
Steps
1Set project and bulk defaults2Review customer rules before saving
1
Set project and bulk defaults
Settings > Preferences has Default Project Type and Default Start Date Offset. Bulk Creation Settings controls whether bulk creation is shown, the naming pattern and the maximum units per bulk. The screen states a maximum of 100.
2
Review customer rules before saving
Below the bulk settings, Customer Settings can require a customer on every project and show the customer column in project lists. Check those choices and use Save Preferences when ready.
That's it!You've completed all 2 steps.
