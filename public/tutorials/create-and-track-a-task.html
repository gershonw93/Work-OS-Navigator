Step-by-step guide

Create and track a task

Keep work, owners, and status together inside your project.

4 stepsAbout 1 min Updated October 11, 2026
Steps
1Open Field > Tasks2Describe the work and pick the right owner3Check the saved task4Move the task as work changes
1
Open Field > Tasks
Choose New Task. Use board, list, or by-assignee view to match the way you run the job.
2
Describe the work and pick the right owner
Enter a clear task and useful details. Set the due date and priority, mark punch items when appropriate, and choose crew or subcontractor. You can select more than one assignee; leaving it blank makes the task Unassigned. Add a follow-up date or photo if needed, then create the task.
3
Check the saved task
List view shows the task and its details together. Filter Open, In Progress, or Completed to focus your list.
4
Move the task as work changes
In list view, use the circle beside the task to choose Open, In Progress, or Completed. Edit the task when its details change; delete only when you intend to remove it and its notes and plan pins.
That's it!You've completed all 4 steps.
