Step-by-step guide

Prepare unit and floor projects

Use one building address with a separate job for each unit or floor.

3 stepsAbout 1 min Updated October 11, 2026
Steps
1Start typing and let the address autofill2Check the unit range and preview3Use Floors for a floor range
1
Start typing and let the address autofill
Projects > Bulk Add > Units. Start typing the building street address and choose its suggested match, then check City, State and ZIP. One building address is shared; the unit number is kept separately so the jobs map to the same building.
2
Check the unit range and preview
Choose a name prefix and client, enter the first and last unit, and choose the project type and start date. Read the count and sample names before using Create projects. The count button tells you how many jobs you are about to add.
3
Use Floors for a floor range
Floors uses the same building-address pattern. Choose what to call each floor, then its first and last number. Review the sample names and job count before creating the development.
i
Each unit or floor is its own job, and counts as one toward your plan.
That's it!You've completed all 3 steps.
